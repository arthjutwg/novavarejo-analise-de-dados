# 📊 NovaVarejo Commerce | Análise de Dados

Projeto de portfólio desenvolvido para demonstrar habilidades em **análise de dados, Excel, Power BI, DAX e Business Intelligence**, utilizando uma base de dados sintética de vendas.

O objetivo do projeto é transformar dados comerciais em indicadores e informações úteis para apoiar a tomada de decisão.

---

## 🎯 Objetivo do projeto

Analisar o desempenho comercial da NovaVarejo Commerce, acompanhando indicadores como:

- Receita
- Lucro
- Margem
- Ticket médio
- Quantidade de pedidos
- Desempenho por produto
- Desempenho por região e canal
- Performance dos vendedores
- Satisfação dos clientes

> **Observação:** a NovaVarejo Commerce é uma empresa fictícia e todos os dados utilizados neste projeto são sintéticos.

---

## 🛠️ Ferramentas utilizadas

- **Microsoft Excel** - organização e estruturação da base de dados
- **Power BI** - construção dos dashboards e análise visual
- **DAX** - criação de medidas e indicadores
- **Business Intelligence** - análise e interpretação dos indicadores

---

## 📌 Principais KPIs

| Indicador | Resultado |
|---|---:|
| Receita Total | R$ 1.445.494,97 |
| Lucro Total | R$ 452.599,97 |
| Margem | 31,3% |
| Pedidos | 1.200 |
| Ticket Médio | R$ 1.204,58 |
| Unidades Vendidas | 1.834 |
| Satisfação Média | 5,56 / 10 |

## 💡 Principais insights

- **Eletrônicos** é a categoria com maior receita.
- A região **Nordeste** apresenta a maior receita da base analisada.
- **Marketplace** é o canal com maior faturamento.
- **Notebook Pulse 15** é o produto líder em receita.
- **Elisa Rocha** apresenta a maior receita entre os vendedores da base.
- A satisfação média registrada é de **5,56 em uma escala de 1 a 10**.
